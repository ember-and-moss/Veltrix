VELTRIX

Lokale Dateiverschlüsselung. Dateien werden in deinem Browser verarbeitet und nicht an einen Server hochgeladen.

1. Datei verschlüsseln

Wähle eine Datei und ein Passwort mit mindestens 12 Zeichen. Du erhältst eine herunterladbare .vltx-Datei.

2. Datei entschlüsseln

Wähle eine zuvor mit VELTRIX verschlüsselte .vltx-Datei und gib dasselbe Passwort ein.

Wichtig

VELTRIX nutzt AES-256-GCM und PBKDF2-SHA-256 mit 600.000 Iterationen. Vergisst du das Passwort, kann die Datei nicht wiederhergestellt werden. Teste zuerst mit einer unwichtigen Datei und bewahre unverschlüsselte Originale sicher auf.

Die Verschlüsselung benötigt einen sicheren Browser-Kontext (HTTPS, z. B. GitHub Pages). Maximale Dateigröße: 100 MB.
